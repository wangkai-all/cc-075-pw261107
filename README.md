# 检验周转分析（Turnaround Analysis）

按科室、检验项目与班次查看从**采样到出结果**的周转时长，可展开单个样本的关键时间点；重采、复测、取消与设备停机分开统计，不把同一份样本的检测过程算成多个独立病人。

全部数据为**虚构生成**，不包含真实机构、人员或患者信息。

## 运行

```bash
node scripts/serve.mjs 4173
# 打开 http://localhost:4173/
```

页面是纯静态 HTML + ES modules，无构建步骤。需要本地 HTTP 服务（`file://` 下浏览器会阻止模块与 fetch）。

重新生成数据：

```bash
node scripts/generate-data.mjs   # 写入 data/dataset.json，确定性随机种子
```

跑统计口径测试：

```bash
node --test tests/*.test.mjs
```

## 口径与规则

### 时间链

```
采样 collectedAt → 接收 receivedAt → 上机 analyzedAt → 出结果 resultedAt
   采样→接收         接收→上机         上机→结果
```

三段各自有目标时长；端到端目标**独立设置**，不强制等于三段之和。

### 班次与业务日

| 班次 | 时间 | 业务日 |
|---|---|---|
| 白班 | 08:00–16:00 | 当日 |
| 中班 | 16:00–24:00 | 当日 |
| 夜班 | 00:00–08:00 | **前一日** |

按**采样时刻**归属班次；夜班跨 00:00 的样本不会被拆成两个班次。日期筛选作用于业务日，因此筛选“10-20”时，10-21 凌晨 00:00–08:00 的样本会被正确包含。标本列表的「采样时间」列显示真实采样时刻，夜班行的班次标签额外标注归属业务日（如「夜班 · 归 10-20」），展开详情中也有完整业务日。配置见 `src/shift.js` 的 `DEFAULT_SHIFTS`。

### 样本分类（互斥）

| 类别 | 处理 | 进入均值 |
|---|---|---|
| 原始样本（正常） | 纳入 | 是 |
| 重采标本 `runKind=recollect` | 单独统计 | 默认否（可配置） |
| 复测轮次 `retestRuns` | 按轮次单独统计 | 否（仅计入复测轮次统计） |
| 取消标本 `status=cancelled` | 单独统计 | 否 |
| 设备停机受影响 | 按规则处理 | 依规则 |
| 待核对（缺失/顺序异常） | 列出待修正 | **始终否** |
| 极端值（超过上限） | 按规则排除 | 否 |

一份标本**最多落入一个类别**，各类计数之和等于命中标本数。

### 患者口径

独立患者 = 所有「时间点完整且未取消」标本按 **患者 × 项目** 去重后的数量。同一患者当天多次采样（复查）只计 1 例患者，其患者周转取最后一次有效结果。复测轮次与重采标本都不会新增患者。

患者口径**独立于均值口径**：调整“重采是否计入均值”不会改变患者数。

### 设备停机

停机窗口按设备登记，可指定受影响的检验项目。统计的是停机窗口与**接收→上机等待窗口**的重叠：

- `mark`（默认）：保留并标注，时间线显示斜纹区间
- `deduct`：从“接收→上机”净时长中扣除重叠分钟（不减成负数）
- `exclude`：凡有重叠的样本整体移出均值

扣除只影响 `receiveToAnalyze` 与 `total`，不影响其它阶段。

### 待核对

以下记录进入待核对列表，**不参与任何均值、中位与超时率**：

- 缺少采样/接收/上机/出结果时间戳（取消样本只要求采样时间）
- 顺序异常：接收早于采样、上机早于接收、出结果早于上机
- 复测轮次缺少开始或结果时间，或结果早于开始

取消时间早于采样时间也会被标记。

### 规则调整预览

规则面板中的改动为**草稿**，实时计算「已应用 vs 草稿」的：

- 纳入标本数、中位总周转、超时样本数、超时率
- 新纳入 / 移出纳入 / 新增超时 / 移出超时 的标本清单
- 待核对数量（数据质量问题，规则不改变它）

点「应用规则」后刷新全部图表与统计。

## 页面结构

1. **总览**：中位总周转（主数字）、患者口径中位、P90、超时、待核对
2. **阶段分布**：四段各自独立刻度的中位 + P10–P90 + 目标线（不拼一条总时间轴，避免长阶段压扁短阶段）
3. **班次对比**：各班次各阶段中位与 P90，附班次时间带示意
4. **科室差异**：各科室中位总周转、超时率；项目横向对比表
5. **超时样本**：可按超时/纳入/停机/复测/重采/排除切换；展开行显示关键时间点、阶段仪表、复测轮次、停机区间
6. **重采、复测、取消与设备停机**：四张分离的统计卡 + 停机窗口明细
7. **待核对**：缺失/顺序异常记录逐条列出，缺失点标红
8. **目标与规则**：目标时长、纳入/排除、停机口径，附影响预览

## 图表设计约束

- 阶段分布为**小多图**（small multiples），每段独立 x 轴；绝不使用双 y 轴
- 同一根轴的刻度只用一个单位（短轴全用“分”，长轴全用“小时”），不出现 `0m / 1.5h` 混排
- 阶段色阶为单色相有序 ramp（已用 `--ordinal` 校验），深浅随阶段顺序加深
- 班次用分类色（蓝/橙/绿），固定顺序，按班次身份而非排名着色
- 超时统一使用 status critical 色，且总是伴随文字标签，不靠颜色单独承载语义
- 每张图都有数据表视图（“数据表”切换），悬停提示仅作增强，数值均可从标签或表格读取
